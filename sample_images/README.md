# Imágenes de Muestra (Entrada)

Coloca aquí las imágenes de prueba que quieras utilizar como referencia de entrada para:
- Edición de imagen (`scripts/demo_image_editing.py`)
- Intercambio de caras (`scripts/demo_face_swap.py`)

### Ejemplo de uso:
- `sample_images/cara_origen.jpg`
- `sample_images/escena_destino.jpg`
